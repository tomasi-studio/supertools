Model Context Protocol

          
One stdio MCP server, three tools.

          

            Run supertools --mcp to speak newline-delimited JSON-RPC 2.0 (protocol 2025-06-18) on stdin/stdout. It serves pick, draw, and view, spawning a fresh window process per call.

Blocking vs. background

              

                pick and draw block the tool call until the user answers or presses Esc—use them only in interactive conversations. view opens in the background and returns {"shown":true} immediately.

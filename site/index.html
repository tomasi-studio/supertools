Visual tools for
terminal agents

A tool and MCP server that lets CLI and TUI agents pop open native windows — so you can pick from image grids, text cards, or annotate screenshots instead of making guesses based on text descriptions or hunting for image file paths in your agent's output.

Under the hood

          
Built for speed

          

            supertools is built in C3 using the milktea framework and sokol_gfx. It runs natively on Mac, Windows, and Linux, all in a slim ~1MB download. The source is MIT licensed and available on GitHub.
